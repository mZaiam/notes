1.1.1. Score Matching with Langevin Dynamics (SMLD)

Score Matching with Langevin Dynamics (SMLD) (Song and Ermon 2019) was the first formulation of the current Diffusion Models (DMs). The idea was to approximate the score function of the data distribution to generate new images. Therefore, given a data distribution \(p_0(\boldsymbol{x}_0)\) with \(\boldsymbol x_0 \in \mathbb R^n\), the goal was to approximate the score function \(\nabla_{\boldsymbol{x}_0} \log p_0: \mathbb R^n \to \mathbb R^n\) with a Neural Network (NN) \(\boldsymbol{s}_{\boldsymbol{\theta}} : \mathbb R^n \to \mathbb R^n\). The reason is that the score function indicates regions in space with higher data density, therefore, approximating this term helps to reach regions in space where the dataset lies.

Although this could be done using a mean squared error approach, the score function only has relevant signal in regions of high data density. Therefore, a denoising approach was used to overcome the fact that real data typically resides on a low-dimensional manifold embedded in a high-dimensional space. In the empty spaces between valid data points, the probability density \(p_0(\boldsymbol{x}_0) \approx 0\), which makes the score function contain close to no information.

To solve this, SMLD corrupted the data with a sequence of Gaussian noise scales, \(\sigma_T > \sigma_{T-1} > \dots > \sigma_1\), where \(\sigma_t \in \mathbb R_{>0}\). The largest noise scale was chosen to be large enough to provide relevant signal across the entire space, while the smallest scale was chosen to be small enough to approximate the clean data distribution. The NN \(\boldsymbol{s}_{\boldsymbol{\theta}} : \mathbb R^{n\times 1} \to \mathbb R^n\) was then trained to predict the score across all the noise levels. For a specific noise scale \(\sigma_t\), the perturbation kernel is Gaussian, being given by: \[ q_{\sigma_t}(\boldsymbol{x}_t \mid \boldsymbol{x}_0) = \mathcal{N}(\boldsymbol{x}_t \mid \boldsymbol{x}_0, \sigma_t^2 \boldsymbol{I}), \tag{1}\] which yields a score of \(\nabla_{\boldsymbol{x}_t} \log q_{\sigma_t}(\boldsymbol{x}_t \mid \boldsymbol{x}_0) = - \frac{\boldsymbol{x}_t - \boldsymbol{x}_0}{\sigma_t^2}\). Therefore, the loss function was defined as: \[ \mathcal{L}(\boldsymbol{\theta}) = \mathbb{E}_{\boldsymbol{x}_0, \boldsymbol{x}_t, t} \left[ \lambda(t) \mathcal{L}_{\sigma_t}(\boldsymbol{\theta}) \right], \tag{2}\] where \(t\sim \mathcal U(0, T)\), \(\boldsymbol x_0 \sim p_0(\boldsymbol x_0)\), \(\boldsymbol x_t \sim q_{\sigma_t}(\boldsymbol{x}_t \mid \boldsymbol{x}_0)\) and \(\lambda(t) = \sigma_t^2\) is a weighting function and: \[ \mathcal{L}_{\sigma_t}(\boldsymbol{\theta}) = \frac{1}{2} \mathbb{E}_{\boldsymbol{x}_0, \boldsymbol{x}_t} \left[ \left\| \boldsymbol{s}_{\boldsymbol{\theta}}(\boldsymbol{x}_t, \sigma_t) + \frac{\boldsymbol{x}_t - \boldsymbol{x}_0}{\sigma_t^2} \right\|_2^2 \right]. \tag{3}\]

To synthesize new data, SMLD employed the Annealed Langevin Dynamics method.

Code

Importing the packages.

import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons

Creating a synthetic dataset.

data, _ = make_moons(n_samples=1000, noise=0.05)
data = (data - data.mean(axis=0)) / data.std(axis=0)
dataset = torch.tensor(data, dtype=torch.float32)

Defining the noise scales for SMLD.

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

L = 10
sigma_1 = 2.0
sigma_L = 0.01

sigmas = torch.tensor(
    np.exp(np.linspace(np.log(sigma_1), np.log(sigma_L), L)),
    dtype=torch.float32,
    device=device
)

Creating a small neural network.

class SMLD(nn.Module):
    def __init__(self, num_scales=10, hidden_dim=128):
        super().__init__()
        self.scale_embed = nn.Embedding(num_scales, hidden_dim)

        self.net = nn.Sequential(
            nn.Linear(2 + hidden_dim, hidden_dim),
            nn.Softplus(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.Softplus(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.Softplus(),
            nn.Linear(hidden_dim, 2)
        )

    def forward(self, x, scale_idx):
        embed = self.scale_embed(scale_idx)
        h = torch.cat([x, embed], dim=-1)
        return self.net(h)

model = SMLD(num_scales=L, hidden_dim=128).to(device)

Training the model.

optimizer = optim.Adam(model.parameters(), lr=1e-3)

batch_size = 128
epochs = 1000
data_loader = torch.utils.data.DataLoader(dataset, batch_size=batch_size, shuffle=True)

model.train()
for epoch in range(1, epochs + 1):
    total_loss = 0.0
    for x0 in data_loader:
        x0 = x0.to(device)
        idx = torch.randint(0, L, (x0.size(0),), device=device)
        used_sigmas = sigmas[idx].unsqueeze(-1)

        z = torch.randn_like(x0)
        xt = x0 + used_sigmas * z

        score = model(xt, idx)

        loss = 0.5 * torch.sum((score * used_sigmas + z) ** 2, dim=-1).mean()

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        total_loss += loss.item()

    if epoch % 100 == 0 or epoch == 1:
        print(f"Epoch [{epoch:04d}/{epochs}] | Loss: {total_loss / len(data_loader):.4f}")

Sampling using Annealed Langevin Dynamics.

@torch.no_grad()
def annealed_langevin_dynamics(model, sigmas, n_samples, n_steps_per_scale, eps=2e-5):
    model.eval()

    x = torch.randn(n_samples, 2, device=device) * sigmas[0]

    for i, sigma in enumerate(sigmas):
        alpha = eps * (sigma / sigmas[-1]) ** 2
        idx_tensor = torch.full((n_samples,), i, dtype=torch.long, device=device)

        for _ in range(n_steps_per_scale):
            z = torch.randn_like(x)
            score = model(x, idx_tensor)
            x = x + 0.5 * alpha * score + torch.sqrt(alpha) * z

    return x.cpu().numpy()

generated_samples = annealed_langevin_dynamics(
    model, sigmas, n_samples=2000, n_steps_per_scale=100, eps=2e-5
)
real_data = dataset.cpu().numpy()
