# Quarto Notes Repository

This is my repository of notes for Machine Learning, Deep Learning and other topics. All content files are organized in `.qmd` files. The files are structured as:

- `_quarto.yml`: contains the general organization of the `.qmd` files, separated by each topic.
- `index.qmd`: contains the home page of the Quarto website.
- `references.bib`: contains the Bibitex references for the texts.
- `style.css`: contains the CSS style of the page.
